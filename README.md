BLESSED FAMILY WEBSITE
A modern family-oriented website built using HTML, CSS, JavaScript, and PHP. The project provides a clean user interface,
interactive features, an image gallery, contact functionality, and an admin approval system for content management.

FEATURES
- Responsive and modern design
- Interactive user interface with JavaScript
- Dynamic image gallery
- Contact form integration using FormSubmit
- File upload functionality
- Admin authentication system
- Content approval and rejection workflow
- Secure admin session handling
- Mobile-friendly layout

TECHNOLOGIES USED
- HTML5
- CSS3
- JavaScript
- PHP
- FormSubmit (Contact Form Service)

PROJECT STRUCTURE
- |-- index.html
- |-- about.html
- |-- contact.html
- |-- gallery.php
- |-- upload.php
- |-- approve.php
- |-- reject.php
- |-- delete.php
- |-- admin_login.php
- |-- admin_logout.php
- |-- admin_approval.php
- |-- flash.php
- |-- styles.css
- |-- script.js
- |-- uploads/

ADMIN FEATURES
The admin panel allows administrators to:
- Log in securely
- Review uploaded content
- Approve submissions
- Reject submissions
- Delete unwanted content
- Manage website uploads

CONTACT FORM
The website includes a working contact form powered by FormSubmit, allowing visitors to send messages without requiring a custom backend mail server.

SECURITY FEATURES
- Password hashing using PHP's password hashing functions
- Session-based authentication
- Protected admin routes
- Flash messaging system for user feedback
- Secure login/logout handling

AIM
This project was developed to demonstrate full-stack web development skills, including:
- Frontend design and responsiveness
- Backend development with PHP
- User authentication
- File handling and uploads
- Form processing
- Content moderation workflows
